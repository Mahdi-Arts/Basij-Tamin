# تحلیل مرجع بصری سازمان تأمین اجتماعی

تاریخ بررسی: 2026-11-15

## دامنهٔ بررسی

- [سایت رسمی سازمان تأمین اجتماعی](https://www.tamin.ir/)
- [سامانهٔ خدمات غیرحضوری سازمان](https://es.tamin.ir/)

این سند از مشاهدهٔ زندهٔ صفحات عمومی تهیه شده است. رنگ‌ها و الگوهای زیر «مشاهده‌شده» هستند؛ به‌معنای ادعای راهنمای رسمی برند یا اجازهٔ استفاده از لوگو و فونت اختصاصی سازمان نیستند.

## الگوهای مشاهده‌شده

### سایت اصلی (`tamin.ir`)

- راست‌به‌چپ بودن کامل رابط و استفاده از ساختار ناوبری چندبخشی.
- زمینهٔ سفید و خاکستری بسیار روشن برای محتوای اصلی.
- تیترهای سرمه‌ای، متن‌های خاکستری و تأکیدهای فیروزه‌ای/سبز.
- تمرکز بر «پنجرهٔ واحد خدمات هوشمند» و دسته‌بندی مخاطب‌محور خدمت‌ها.
- وجود کنترل‌های دسترس‌پذیری برای اندازه و ضخامت فونت و رنگ زمینه/متن.

### سامانهٔ خدمات غیرحضوری (`es.tamin.ir`)

- هدر سرمه‌ای با ناوبری روشن و عنوان سازمان.
- بخش قهرمان با عنوان «سامانه خدمات غیرحضوری» و دو اقدام اصلی ثبت‌نام/ورود.
- کارت‌های تصویری برای بیمه‌شدگان، کارفرمایان، مستمری‌بگیران، خدمات سلامت و «تأمین اجتماعی من».
- تأکید پررنگ بر سرویس‌های غیرحضوری و مسیرهای کوتاه و مستقیم.
- فوتر شامل اطلاعات تماس، پیوندهای رسمی و اعلان حقوق مالکیت.

## تصمیم اجرایی پروژه

تم جدید در `src/css/tamin-theme.css` پیاده شده است. این لایه فقط هویت بصری و خوانایی را بهبود می‌دهد و منطق انتخاب نیت، پرداخت آزمایشی، ویجت قابل درج و صفحهٔ ویدیو را تغییر نمی‌دهد. دارایی‌های رسمی سازمان، فونت اختصاصی آن و لوگوی سازمان در پروژه کپی نشده‌اند؛ پروژه از فونت و دارایی‌های خود استفاده می‌کند.

## معیار پذیرش

1. همهٔ صفحات فارسی `dir="rtl"` و فونت محلی `Vazirmatn` را حفظ کنند.
2. مسیر کارت‌ها → پرداخت و مسیر ویجت → پرداخت بدون تغییر منطقی باقی بماند.
3. فوکوس کیبورد روی کنترل‌ها با حلقهٔ کنتراست‌دار دیده شود.
4. پالت جدید در موبایل و دسکتاپ خوانا بماند و اطلاعات فرم در زمینهٔ سفید نمایش داده شود.
5. بازگشت به وضعیت قبل با حذف لینک تم و کلاس `tamin-theme` ممکن باشد.
